# Bzgz Proxy

ربات تلگرام + مینی‌اپ که به هر کسی اجازه می‌دهد **پروکسی WEB تلگرام** شخصی را روی **اکانت کلودفلر خودش** بسازد. رایگان، بدون سرور و بدون VPS.

[English](README.md) · **فارسی**

## امکانات

- **اشتراک با اسم** — دوستت توی ربات `saman` (و رمز اختیاری) می‌نویسه و بدون توکن از پروکسی تو استفاده می‌کنه؛ **صفحه‌ی حجم** روی لینک هر پروکسی؛ **آپدیت دستی** با اعلان داخل پنل؛ تست پینگ.
- **ساخت پروکسی با چند کلیک.** کاربر یک‌بار توکن کلودفلر را می‌دهد و ربات پروکسی را روی اکانت *خودش* می‌سازد. توکن فقط برای همان یک درخواست استفاده می‌شود و **هیچ‌جا ذخیره نمی‌شود**.
- **ربات و مینی‌اپ** به سه زبان فارسی، انگلیسی و روسی.
- **چند پروکسی برای هر کاربر** (برای هر نفر از خانواده یکی)، تغییر نام، آپدیت، حذف و نمودار مصرف.
- **پایش سلامت.** اگر پروکسی قطع شود، پیام تلگرام می‌گیرید.
- **جوین اجباری** (کانال عمومی یا خصوصی) با قفل `/lock on|off`، هم در ربات و هم در API مینی‌اپ.
- **کنترل پروکسی** در مینی‌اپ: وضعیت، خاموش/روشن، لینک جدید، آپدیت، تغییر نام، حذف.
- **لوکیشن ثابت سرور** (خودکار / اروپا / آمریکا / آسیا) و **آپدیتی که تنظیمات همه‌ی کاربران را نگه می‌دارد**.
- **تیکت پشتیبانی**، پنل مدیریت، بن و آزادسازی، پیام همگانی.
- **هسته‌ی پروکسی v4.** صفحه‌ی طعمه‌ی فارسی متفاوت برای هر دیپلوی، `/health` کلیددار، مقایسه‌های زمان‌ثابت، سقف اتصال برای هر IP و کل، و فیلتر اختیاری کشور.

## چطور کار می‌کند

```
اپ تلگرام ──HTTPS/WebSocket──▶ ورکر کلودفلر کاربر (هسته) ──WebSocket──▶ سرورهای تلگرام
                                      ▲ گزارش مصرف
ربات و مینی‌اپ (ورکر این ریپو + D1) ┘ پروکسی‌ها را می‌سازد و پایش می‌کند
```

دو نوع ورکر وجود دارد:

| ورکر | کجا اجرا می‌شود | کد |
|---|---|---|
| **ربات** (مدیریت) | اکانت کلودفلر شما، با دیتابیس D1 | `src/worker.js` و `src/app.html` |
| **هسته‌ی پروکسی** | اکانت کلودفلر *هر کاربر* | `src/core.html` (ربات آن را دیپلوی می‌کند) |

جزئیات: [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md)

## شروع سریع

نیازها: Node.js نسخه‌ی ۱۸ به بالا، اکانت کلودفلر، توکن ربات از [@BotFather](https://t.me/BotFather) و آیدی عددی تلگرام خودتان.

```bash
git clone https://github.com/<you>/bzgz-proxy && cd bzgz-proxy
npm install
npx wrangler d1 create bzgz-proxy      # database_id را در wrangler.toml بگذارید
npm run db:init
# OWNER_ID را در wrangler.toml تنظیم کنید و بعد:
npx wrangler secret put BOT_TOKEN
npx wrangler secret put WH_SECRET      # یک رشته‌ی تصادفی بلند
npm run deploy
# یک‌بار در مرورگر باز کنید تا وب‌هوک، منو و دستورها ثبت شوند:
# https://<your-worker>.workers.dev/setup/<WH_SECRET>
```

راهنمای کامل: [docs/SETUP.fa.md](docs/SETUP.fa.md) · [English](docs/SETUP.md)

## تست

```bash
npm test      # Node 22 به بالا
```

تست سرتاسری، کلاینت تلگرام، صفحه‌ی بریج، ورکر و سرور بالادستی تلگرام را شبیه‌سازی می‌کند. با تلگرام یا کلودفلر واقعی ارتباط **نمی‌گیرد**، پس رفتار با کلاینت‌های واقعی ممکن است فرق کند.

## محدودیت‌ها و سلب مسئولیت

- پلن رایگان کلودفلر محدودیت درخواست و CPU دارد (مثلاً ۱۰۰ هزار درخواست در روز برای هر اکانت). مصرف سنگین ممکن است محدود شود.
- دامنه‌های `*.workers.dev` در بعضی کشورها فیلتر هستند. دامنه‌ی اختصاصی روی کلودفلر کمک می‌کند، ولی خودکار تنظیم نمی‌شود.
- هر کاربر روی اکانت **خودش** دیپلوی می‌کند و مسئول رعایت شرایط استفاده‌ی کلودفلر و قوانین کشور خودش است. قبل از راه‌اندازی پروکسی شرایط را بخوانید.
- این پروژه وابسته به تلگرام یا کلودفلر نیست و تأیید آن‌ها را ندارد. بدون هیچ ضمانتی ارائه می‌شود (فایل [LICENSE](LICENSE)).
