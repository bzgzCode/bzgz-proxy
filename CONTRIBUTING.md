# Contributing

Thanks for helping! / ممنون که کمک می‌کنید.

1. Fork, create a branch, make your change.
2. Run `npm test` (Node 22+). Add a test in `test/e2e.mjs` for behaviour changes in `src/core.html`.
3. Keep user Cloudflare tokens out of storage and logs.
4. Never commit secrets or personal ids. Check `git diff` before pushing.
5. Open a pull request describing what changed and why. User-facing strings need English, Russian and Persian.

Bug reports: use the issue template and include the Worker log lines (without secrets).
